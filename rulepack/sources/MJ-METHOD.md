# 明镜数学与取数方法规范 v3

金额以Decimal元保存，取数只使用同公司、同科目、同期间、同口径并受研报日截断的证据。
金额与增长率按原文显示精度生成区间，不能以模型输出作为事实、公式或裁决。
同报告比较数用于同比基数，指定来源只从被引用报告取值。
受限公式只允许已登记输入、常数、四则运算、绝对值、比较及比较的逻辑与或，分母区间非正或触零时弃权。
按项目计划书第5.5节，两侧披露区间相交即相容核实；四舍五入区间为[v-q/2,v+q/2)，q按原披露单位和小数位计算。
授权公式的期望区间由各操作数区间传播；相容核实不表示较细的精确位数已独立核实，来源较粗时修正应返回披露区间。
正数约或左右在披露区间两侧额外相对放宽h，默认h=2%；正数逾、超过、多于使用(v,v*(1+h)]，正数近、将近、接近、不足、不到使用[v*(1-h),v)。
负数或零的模糊词没有签发区间定义时弃权X2；仅金额巧合不证明期间、口径或披露版本错误。
现金含量阈值0.5、扣非占比阈值0.30为团队设定参数，不能称为监管阈值。
