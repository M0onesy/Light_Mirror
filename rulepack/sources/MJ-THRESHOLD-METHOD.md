# 来源引述阈值断言方法 v1（工程草案，专业签发待审）

来源阈值断言使用独立集合，不作为点事实；严格或非严格上下界分别保留开闭端点，未披露的端点记为缺省，不用无穷Decimal、零或100%填充。

来源谓词蕴含规则：在发行人、有效期间、分子分母定义、引用、披露版本和截止日均已由可信程序核验后，来源允许集合完全包含于陈述允许集合时核实；两个集合完全分离时违背；仅部分相交时未确定。

计算式：下界蕴含且上界蕴含，或来源完全位于陈述以下，或陈述完全位于来源以下，才是可确定的集合关系。端点相等时，包含与分离须分别考察两侧端点的开闭性。

本规则只证明来源陈述逻辑支持或否定引述谓词，不证明任何精确财务比例。来源“超过70%”蕴含同定义“超过70%”，不能当成70%点事实，不能支持“超过80%”，也不能支持71%精确值。

这是计划要求中范围断言的独立T3工程方法，不能替换计划书5.5节默认h=2%的模糊限定词兼容政策，不改动FIN-range既有有限闭区间规则。不据相近金额、相同数字字符串或其他季度比例推定定义与期间。

调用本数学操作前必须验证原始引文、文档哈希、页级证据、声明来源、稳定发行人身份、有效期间、分子及分母定义、单位量纲和合法披露时序。身份、版本或来源存在歧义时，不进入集合判定。

有效来源绑定使用独立证据对象；模型只可选择已登记资源和语义身份，不可提交来源端点、点事实、自由公式或判定。端点由可信解析器从原文确定性提取。

来源为取整点值时，应先用其披露精度建立半开区间，再做谓词蕴含判断；不能因为与谓词区间相交就认定谓词成立。70%的取整区间跨越70%时，不能证明严格超过70%。
