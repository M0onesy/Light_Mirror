# AI 使用与可信边界

在线执行使用锁定 Harness 原生循环，Python 不模拟 Agent Loop。planner 与 verifier 在独立会话中完成六字段绑定，不见对方历史或结果；待核金额及邻近金额被屏蔽。一致且关键字段明确后才核查。同一基础模型的两个会话不意味着统计误差独立。

金融工具经 Node→Python 私有 RPC 调用共享 dispatcher。身份由可信宿主注入，模型不能指定角色、session、call ID、run ID 或资源锁。金额真值、自由公式、判定、任意路径和跨公司绑定被拒绝。reporter 和追问仅提交注册标题及可信槽位，数字和结论由宿主填入。

路由在任务排队时冻结，改配置只影响后续任务。密钥来自 Windows DPAPI，按授权供应商引用经受控 RPC 获取；不加载明文 credentials-local，不自动跨供应商降级。DeepSeek 原生协议的 AUTO 使用低延迟 off，其余供应商按自身适配器处理；显式思考设置保留。

审计保留请求/响应哈希、路由、工具及版本锁、Token 用量和降级。未知用量/费用显示 unknown。产品不展示私有思考；缓存保留协议必需的重放元数据并脱敏，不把思考当结论。

内核重放重新计算事实；Agent 重放用匹配缓存驱动真实 Harness 工具循环，缺缓存禁止联网。材料、判定、插件或版本变化拒绝恢复，不改旧锁。

AI 实现和代理复核不能冒充独立真人标注或规则签认。评测数字须来自实际脚本，生成机制集与真实全文质量分别登记。
