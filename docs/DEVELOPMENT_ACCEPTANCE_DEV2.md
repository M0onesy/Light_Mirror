## 本次完成的实际功能

- 原生 Harness 分别完成 A/B 独立绑定、事实查询、规则查询、确定性判定与报告提交。所有数字仍由明镜内核计算；模型不能提交金额真值、自由公式或判定。
- 追问查询继承原任务公司、期间、分析口径、材料锁和模型配置；营收同比直接读取登记指标与冻结槽位。
- 原文追问具有独立消息证据登记。搜索支持空白归一化，并按标题读取同页实质正文；表头、目录与纯金额行不会优先作为解释。模型只接收一份原文，完整证明留在宿主。
- 会计政策、估计及差错事件识别已接入真实财报分析、CLI 和双层重放。事件为披露复核事项，不能冒充数值 verified。缺少公司或合法披露日期的段落、未来披露、明确否定和无关生产安排不会生成正事件。“不适用初始确认豁免”与“未发生变更”分别处理。
- 归母净利润仅按原文科目定义和 CAS33 第三十六条确定合并口径。独立 YOY 行继承已验证的原始科目标签与字符区间；普通营收、普通净利润和未知 EPS 定义不借用这一口径。明确相反口径、否定或混合声明继续弃权。
- 跨行预测保留精确来源；图轴排除保留原始 occurrence 与理由。所有未解析金融候选仍可见，不能通过模型未选中而删掉。
- 追加财报保留原语料，补口径或补材料创建新任务版本。旧结果、材料锁和历史审计不改写。
- 追问默认 Token 预算为 64,000，Web 可修改。已明确配置的预算保留；本次真实新任务使用独立的 64,000 Token 配置快照，用户保存的配置与密钥文件均未变更。
