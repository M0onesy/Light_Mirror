# 财务内核 v2 与评测落实记录

本文件描述可运行代码与实际检查，不将生成测试或开发材料观察写成金融专业最终验收。

## 已实现的边界

`Fact` 使用有限 Decimal，并登记 `parse_conf`、抽取版本、披露日期和原文证据。`FactStore.query` 支持 `latest_as_of`、`same_report`、`pinned`；同报告计算限定同一来源，有截止日时缺失或非法披露日期不能通过筛选，新披露低置信度或矛盾事实不偷偷退回旧版本。

`AtomicClaim` 增加 `binding_status`、`parse_status`、`modality`、`query_strategy`、`approximate`。`SemanticBinding` 拒绝模型提交自由数字、候选值、公式和结论。X1—X6 分别区分缺事实、公式或非正基数、语义未知/不一致、置信度/冲突/缺日期、版本敏感缺研报日期、无法确定性解析。A1—A5 提示明示旧源、近似措辞、净利润用语、冲突和分析信号。

未知合并/母公司口径明确弃权，不能默认合并。同比非正基数、未知 EPS 定义、净利率和 ROE 的不同定义不强行套公式。非经常性损益重算须明确总额、税项、少数股东影响及符号；普通披露的带符号少数股东影响保存为 `NRI_MINORITY_RAW`，不直接灌入减法规范操作数。表格的 `-` 保留缺失，不擅自当零。

`analysis.py` 实现证据绑定的指标、扣非重算和利润/现金流变化分析；两次连续背离需要三个相邻期间，三次需要四个。版本变动事件不能凭数字变化推断会计政策、估计或差错原因；会计事件仅接受明确、已冻结、有来源的段落。

规则包 0.4.0 包含 30 张卡和 60 个口径条目。公式 AST 限定登记输入和常数、四则运算、绝对值与比较；禁属性访问、下标、导入、任意调用和未登记字面常数。规则卡有量纲、正反边界例、来源条款快照、归一化哈希和生效信息。`rules check` 的机器校验通过并不代表专业签认：审核人仍为空，部分非经常准则来源和生效登记缺项，会单列 `professional_signoff_status=pending`。

## 表格与 PDF

`table_mentions.extract_table_mentions(text,pages,blocks,company,period)` 接受 coverage 的页面和块绝对字符偏移，逐个返回原文数字单元格。重复出现不删除。只从可靠金融标题、期间列和完整科目行绑定；缺列、缺单位或支持不了的数字明确 X6。2024E 等预测列和估值行在 ledger 作为范围外可见项保留，不进入历史数字判定。

支持研究报告中的百万元、YOY 行继承前一科目、金额/同比区分、年度列、换行标签。每张新表清空单位，行内单位只作用本行。无法区分并排表单位时保留 unresolved，不依赖跨列猜测。PyMuPDF 文件资源显式关闭，pdftotext 降级按换页符保留原 PDF 页码。

事实解析新增营业总成本与主营成本区分、披露毛利率、净资产收益率、资产负债率、非经常合计及影响额标签。科目边界拒绝“营业收入增长率”被当营业收入金额。研报日期仅是截止日，绝不填充财报缺失公告日期。

## 实测记录及限制

`runs/generated-agent-bench-v3` 为真实脚本生成的 354 条机制测试：判定严格匹配 354/354，误纳 0/240，修复合格及复查均 240/240；95% Wilson 区间已登记在 metrics.json。它没有原 PDF 人工真值、真实模型会话或单元格定位，不能作为 CRRV 专业准确率。之后代码继续改动，v3 是保留的中间观察；冻结验收必须新建运行目录。

`scripts/table_material_qa.py` 对 44 页开源证券并行科技首次覆盖研报与 2023 年真实年报执行不调用模型的抽取观察。`runs/original-table-qa-v1/qa.json` 登记原文件哈希、466 个表格数字出现的精确原文 span、195 个历史出现、267 个预测出现和四个估值范围外出现。原文字符定位 466/466；历史中 34 个已解析、161 个未知；全部原始核查合法弃权（34 个 X3 口径未确认，161 个 X6）。这是对未完成语义/表格范围覆盖的透明观察。

单独列出的“暂时假设合并口径”诊断只检验数字与计算机制：34 条中 30 verified、四条负基数 X2，11 个证据引用可返回真实年报第 8、80、81、84、85、88 页。该假设不是人类标注，也不是最终模型绑定结果，不能用 30/34 宣称业务准确率。真实语义绑定准确率、表格召回率和物理单元格命中率仍未知。

## 最终验收仍需完成

P/A 的独立人工原 PDF 真值、专业规则签认、未使用 D3 公司封存及一次性评测、原生 Harness 双盲会话基线、多供应商真实 API 回归、打包后的断网冷启动与三次重放。`bench/v1/README.md` 说明一次性执行保护；开发 Agent 不代签人类审核。现有源代码测试证明已实现机制边界，尚不足以宣称最终金融专业验收通过。
