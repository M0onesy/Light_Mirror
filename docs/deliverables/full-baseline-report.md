## 二、draft 生成方法与抽取规则

**脚本：** `scripts/build_fulltext_draft.py`（本次新建，`py -3.12` + `pymupdf`）
**产出：** `samples/real_broker_full_draft.md`，**共 197 条**

抽取由两条互补的来源构成：

### 2.1 正文金融表述句（37 条）
- 逐页读取文本层（`pymupdf`，非 `fitz`）。
- 按行累积到滚动缓冲区；一旦缓冲区出现句末终止符（`。！？!?`）即切出完整句，因此软换行正文句可被正确重组，且一行多句会被拆开。
- 仅保留含金融数字的句子，匹配 `\d+(\.\d+)?\s*(亿元|万元|亿|百万元|万美元|亿美元|万|%|％|倍|元/股|元|EFLOPS|Pflops|核时|卡时|台|个)`。
- **排除噪声：** 目录页（点线 `....` 占优）、图注/表注（`图N：`/`表N：`开头）、页码行（`N / 44`）、running header（"北交所首次覆盖报告"）、免责声明行、数据来源行（`数据来源：`/`资料来源：`）、章节标题（`1.2、`/`看点一：`）、坐标轴纯数字碎片、无足够中文的表格碎片、关键数据表头块（`指标(单位)` 括号标签出现 ≥3 次）、过短（<8 字）与过长（>130 字）句。

### 2.2 附录财务预测摘要（第 42 页，结构化重建，160 条）
- 第 42 页表结构为「指标 + 五期数值（2022A/2023A/2024E/2025E/2026E）」。
- 脚本识别「标签行 + 恰好 5 个纯数值行」的固定模式，重建为陈述句：`公司[预计]{年}{指标}为{值}{单位}。`
- 仅保留一组**策划好的核心指标**（利润表/成长/获利/偿债/营运/现金流/每股/估值，共 32 项 ×5 期 = 160 条），避免资产负债表全部明细行污染 draft。历史期以「公司YYYY年…」，预测期以「公司预计YYYY年…」，单位按指标来源推断（百万元 / % / 元 / 倍）。

> 说明：正文抽取按设计排除纯表格行；第 42 页摘要表作为**结构化重建**单独成节（复刻小基线 draft 的全部语义），是达标 100–200 条的关键来源，两条来源在文件中以「## 一、正文…」「## 二、附录…」分区标注。

## 七、结论与局限

**结论：**
1. 全文 44 页基线在 126 条候选上给出 **97.62% 弃权率**，与 27 条小基线（96.30%）量级一致，证明高弃权率是**结构性、可复现**的，而非小样本假象。
2. **A 改造护城河稳固**：OFF 与 ON 在全部 126 条上 `(status, abstention_code, error_type)` **零差异**，探查纯粹只读、永不改判。
3. 弃权主因清晰：**X3 口径未声明（67 条，占 53%）** 与 **X6 源维度缺失（34 条，占 27%）** 合计约 80%；探查命中 31 条「事实存在但被 X3 守卫拦截」的可救条目，构成补口径声明的优先修复池。

**局限：**
1. draft 实际候选 126 条，未达原目标 319 条——受限于**单篇 44 页研报真实金融表述的可得数量**；正文纯散文仅含约 37 条金融句，其余金融数字多位于图表/表格（按规则排除），故辅以第 42 页摘要表结构化重建至 197 条。
2. 正文抽取句存在少量 PDF 文本层残留（如行内多余空格、个别截断句），不影响金融数字维度识别，但可用性上略低于人工撰写的小基线。
3. 「可救」仅表示**探查命中同维度事实**，是否最终可 verified 仍取决于口径声明的有效来源与载体规则，需后续补证实验确认。
4. 本基线仅覆盖**单公司单篇研报**，跨公司/跨券商的外推需更多样本。
