# 原文维度与保守取数政策

本文描述目前已经实现的运行边界，不代表真人金融验收成绩。

`Fact` 和来源绑定现在保存币种、业务／客户维度及指标定义标识。金额标准化仍在各自币种内换算单位；同币种核查无需汇率。原文明示美元、港元、欧元等外币金额时，不能将“亿美元”截断为人民币“亿”，也不能消费同数值人民币事实。缺少同币种事实返回 `X1`，币种未知或冲突返回 `X3`。目前没有跨币种汇率换算规则；人民币正常金额与股份统计不会因材料里另有外币而改变币种。

财报表段明确声明受支持币种时，普通解析保留该币种事实；币种冲突或未确定时仍不准入，局部重解析保留阻断原因。进入新报表重置声明，局部行的单位和币种不能成为另一报表的依据。本版本不做隐含汇率换算，不把缺少同币种材料当作数字错误。

明确的“2020–2022年……分别为 a、b、c”只在期间数与连续原文数值数一致时按顺序绑定。尾部明确单位可以作用于同一个连续列表，如“1、2及3万元”；不可跨句或跨块借用。季度、上半年与下半年保留其期间类别。数量不匹配、次级“分别”列表没有独立期间映射或缺少足够单位证据时不猜最后一年，继续弃权。

页年、日期、技术量、持续时间和有表头及 PDF 列坐标证明的序号均保留在全文 occurrence 账本中，并登记排除原因与原文依据。不会凭金额形似年份、大小或邻近词删除合法金额及百分比。金额和比率范围保留完整端点，使用已登记的区间规则；前提、口径或方法缺失时弃权，不把 `1000-3000元` 的连接号误读成单点负数。增长率后接金额（如“增长55%至4.14亿元”）不是金额范围。

以上源维度均在语义绑定之前由原文冻结；模型不能用候选金额、相近事实或改写关系来绕过。报表口径不明时仍要求源材料或用户有来源的补充声明，不能默认为合并口径。

数字解析与语义定义分开建账。数值、单位、期间已经确定，但原文只称 ROE、EPS、净利率、摊薄 EPS、现金、长期投资或未定义费用率时，保留 `parsed` 数字、原科目标识和 `semantic_review_required`，实际送入独立 A/B 会话审阅。没有来源定义就提交未知字段，不能凭双模型一致把 ROE 升格为加权 ROE、摊薄 EPS 升格为法定稀释 EPS，或现金升格为货币资金。原始标识继续约束内核：缺金融定义返回 `X3`，缺授权费用率聚合与分母公式返回 `X2`；这些均不等于数值无法解析的 `X6`。

任务输出的 `semantic_review_candidates` 和 `semantic_review_submitted` 分别统计待审数字与 A/B 均实际提交的数量。取消、预算耗尽或缺一方提交的已解析数字保留 `pending` 和 `partial`，不能预先批量结算为弃权。语义已经审阅、未知定义依法弃权与已经执行数字核查是不同进度；原生核查工具计数只证明实际执行该工具链。

英文 EPS、ROE 等缩写按大小写无关的完整标识符边界识别，不把 STEPS、EPSILON 或 EPS2 当作 EPS。绑定工具的原文、嵌套表格元数据及源维度中的公司主语和限定词全部在响应层屏蔽候选及相邻金额；内部冻结的源证明保持原始内容，继续用于一致性守卫、恢复和重放。

`scripts/source_semantic_review_audit.py` 可以只读对照归档运行，输出原文件前后哈希、occurrence 是否守恒、数字解析与语义待审迁移，以及新增有依据的噪声排除。该脚本和小型回归 fixture 是开发观察，未调用模型，不是独立真人金标或金融召回成绩；真实工具执行仍须重新运行冻结版本。

正文与表格的裸“净利率”和“净利润率”执行同一政策：原文必须明确分子与营业收入分母。NP/REVENUE 与 NP_PARENT/REVENUE 已分别登记，归母净利率不能调用净利润分子规则。附近利润金额或仅称“按净利润口径”不能证明分母，继续 `X3`。单项管理／销售／研发／财务费用率使用各项费用除以营业收入；聚合费用率必须明确组成，不能以费用同比替代。规则包目前为工程验证版本，真人专业签发仍待执行，旧运行锁保持不变。

中文“每股收益(最新摊薄)”与 EPS 摊薄一样，是合法数值但股数定义待审；不能当作法定稀释每股收益。明确“每股指标（元）”等局部子节可提供元单位，保存可按原文字符区间反查的 `source_unit_proof`，同时保留期间和预测列来源。该单位只作用于同一页、同一报表与同一 PDF 物理列；新报表、金额单位声明或其他财务子节重置它。每股数不能借用利润表或现金流量表的百万元/万元单位，也不能仅因“摊薄”二字就猜元。缺单位仍 `X6`；已解析且有单位、但股数定义不明则进入真实 A/B 后 `X3`。

原 `samples/demo_draft.md` 保留历史字节。新受控演示 `samples/demo_draft_defined.md` 在净利率条目明示 NP/营业收入定义，保留数字原值和三态核查场景；它是虚构产品演示，不是增加独立事实或修改评测金标。

登记的券商指标或现金流桥接标签现在与数字解析分离：EBITDA、ROIC、流动/速动比率、周转率、营运资金变动、其他现金流、每股现金流/净资产等保留独立 `_UNSPECIFIED` 来源标识。只有年度列、合法数字和本表量纲可证明时进入语义审阅；缺授权指标公式返回 `X2`，桥接聚合或股数定义未知返回 `X3`。无量纲比率/周转次数来自明确原文标签，百分比和金额仍按其明确单位读取。财务报表单位及每股元子节保存字符区间出处，不能跨 PDF 物理列借用。现金流量表的“短期借款”“长期借款”表示桥接变化，不能使用资产负债表期末借款余额。该来源标签集合独立于 canonical 事实和工具账户枚举，模型仍须提交未知字段；本轮没有添加新事实取数权限或指标公式。不登记的标签、缺单位/列标题仍 `X6`，理由表示源维度或结构解析不足，不称合法数字损坏。

技术大会 HPC China 换行年份、明确标点边界后的“1）”正文序号均保留有依据的排除条目。图轴排除统一要求本图引用、等间距 PDF 刻度以及位置相容的原文年份或类别横轴，保存 `pdf-chart-layout.v1` 证据。标题中的季度和另起一行的系列图例不能代替真实横轴；缺少横轴证明的六个百分比位置全部保留为待处理，不凭外观排除。缺几何、缺横轴或真实财务比例表同样不排除；已有真实横轴不必另有系列图例。估值 PS/EV-EBITDA 依据原文标题或行标签标记范围外并保留 occurrence。纯百分比列表和连接词片段不产生虚构公司主语；后续真实“乙公司”仍按另一公司拒绝取当前任务事实。每项范围外或规则排除都保留原文区间，支持不了的金融指标继续作为可见工作项。
