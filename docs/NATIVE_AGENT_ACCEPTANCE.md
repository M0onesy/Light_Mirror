# 原生金融 Agent 架构与候选验收

本版统一入口与实施契约见[SMART_PIPELINE.md](SMART_PIPELINE.md)及[PROJECT_TASK_MANUAL.md](PROJECT_TASK_MANUAL.md)。以下保留原生架构与验收标准，历史运行路径/数字不改写为1.0.0.dev3成绩。


## 版本与框架

当前应用为 `1.0.0.dev3` 源码开发版；下述原生历史观察保留各自原版本，旧 `1.0.0rc1` EXE 保留为历史记录。Harness 来自本地 `0.1.6-alpha.2` archive 快照；上游 commit 缺失，登记 null，不混装公开 PyPI 其他版本。独立 Windows x64 金融运行时、金融插件、profile 和依赖按 manifest 锁定，开发机已验证脱离系统 Node 和上游依赖目录。Python 客户端实现 stdio 传输及生命周期扩展，不重写原生 Agent Loop。

## 执行

```text
Web → 宿主冻结材料与配置 → 全文页/块/数字账本
→ planner / verifier 原生独立会话 → 六字段一致性闸
→ coordinator 原生查询事实、规则、核查 → Decimal 内核
→ reporter 槽位模板 → JSON / Markdown / HTML / 审计
```

确定性无法解析的提及为 X6，已提交未知/分歧为 X3；未提交绑定保留 pending。停止原因、预算耗尽与降级分别记录。宿主已接受的不可变工具输出可在最终文字截断时保留，但不消费截断文字，审计记录 `model_turn_incomplete`。

四个标准 MCP 使用官方 Python SDK 2.3.0，包含初始化、工具描述与调用，复用 dispatcher。金融 profile 不加载 Shell、Code Mode、开放搜索、自修改或遥测，模型 API 仅连接选定供应商。

双盲屏蔽覆盖原文、相邻单元格，以及表格标题、行标签和表头的来源文本；期间、单位及原文位置保留。屏蔽后的工具输出是副本，不改写原始提及或冻结材料。显式外部运行时缺失的检查在完整内嵌资产解包之前执行，冷缓存故障也必须及时降级。

真实开发研报曾暴露十项非法维度比较：CAGR 被当作营业收入，以及分业务收入/毛利率被比到公司整体。现保留目标数字的原文局部位置，原文定义检查在事实查询前执行；模型绑定不得移除分部限定。通用产品、业务线、服务及地区限定同样不能消费集团事实，即使金额相等；后续明确公司整体科目可重置口径。当前未建立匹配分部事实维度或授权 CAGR/占比/百分点差公式时明确弃权，不能给出集团值作为所谓修正。重复数值只修改目标出现。旧失败运行不改写。

追问工具按问题、科目、期间和提及 ID 筛选，默认五项分页，每次响应最多 16 KiB UTF-8；只返回当前页证据及槽位，不截断数字或证据。报告只允许引用本会话工具实际读过且在资源范围内的槽位。一次摘要不代表全文完成，完整内容及未处理部分始终保留在冻结报告和覆盖账本。

金额展示与提及解析共用单位倍率，包含研报表格常见的百万元；展示取整值须能回解析到原值容差范围内。同比及环比的非正基数统一弃权。

取消保留未冻结状态、A/B 提交、工具 ID、请求/Token/时间累计预算和原生 descriptor。恢复检查配置、材料、内核、编排、插件及运行时锁，并使用原生 resume；重启不能重置整任务预算。补材料新建版本。财报指标、信号及追问答案仅引用证据和内核槽位，不生成投资结论。

追问预算按每次消息计，新建或未显式设置 Token 预算的配置默认三分钟/十二次模型请求/八十次工具/64,000 Tokens；已有明确保存的预算不自动覆盖，Web“角色与预算”中可调整。配置更新仅影响后续任务，当前任务与材料会话继续使用冻结配置。原生会话历史跨消息保留。重建宿主后若临时分析槽位不在原冻结任务中，须重新调用登记分析工具取证，不能仅凭历史槽位生成数字。
