覆盖账本保留每个原文数字出现及 pending、judged、abstained、out_of_scope、rule_excluded 状态。`partial` 表示候选提及没有处理完整；处理完成不代表全文召回达标。报告 HTML、Markdown 与 JSON 显示同一冻结三态、X1—X6 弃权原因、A1—A5 提示、规则 ID、公式、操作数、证据和五项修改建议。财报分析中的团队阈值只用于复核提示，不当作会计准则结论。

历史财务首版观察支持收入、成本、净利润/归母/扣非、经营现金流、资产/负债/权益、基本每股收益、披露 ROE、毛利率、净利率、资产负债率、现金流含金量和扣非重算。合并/母公司、年度/半年度/季度/累计、金额/百分比、公告时点/重述版本分别匹配。非正基数、缺税项或少数影响、缺单位/列标题、EPS 摊薄定义、泛称净利率/ROE、版本敏感缺日期明确弃权。政策/估计/差错事件只从明示已冻结段落识别，不能由版本金额变化推断原因。
