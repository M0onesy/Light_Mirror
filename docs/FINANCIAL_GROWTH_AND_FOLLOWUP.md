# 同比分析与追问的来源边界

财报分析新增营业收入、归母净利润、经营现金流同比，使用登记规则 `E5-yoy` 的 `(current-base)/base`。所有输入、结果与单位仍由 Decimal 内核产生；模型只能筛选登记指标和引用冻结槽位。

比较数必须与本期金额来自同一披露版本、同一公司和同一报表口径。年度对上年年度、半年度对上年半年度、单季度对上年同季度。缺少本报告比较数时不借用旧报告未调整金额；零基数、负基数按 X2 弃权，保留实际取得的操作数和证据。缺少回溯日期时按 X5 弃权，不读取未截断事实。

JSON 中标准金额为元、每股值为元/股、比率和同比为小数。Web 显示相应单位，导出 Markdown 与 HTML 采用同样量纲。中文分析槽位可提供百分比展示，标准值和原始证据继续保留供复核。

材料追问继承原任务冻结的公司、分析口径与配置。母公司任务不会因为当前设置默认合并而切换口径。新材料或新口径建立新任务版本，旧结果只读。

追问准备阶段只重读原草稿及锁定报告，不把事实索引或源维度证明当作财报。解析使用同一取消事件、阶段进度和任务截止时间。供应商和原生运行时失败会明确显示，不能用失败消息代替完成的工具核查。

以上是实现与测试说明，不是独立真人金融金标、全新 Windows 或最终 EXE 验收结论。
