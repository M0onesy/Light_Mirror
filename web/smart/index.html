      明镜怎样核查
      
    
        
      
      1. 识别与入库：按内容哈希去重存入本地知识库；从文件内容识别文档类型、公司、证券代码、报告期和研报日期。
        2. 
      
      2. 抽取：财报的三大报表、主要会计数据、分季度、非经常性损益、分产品收入、现金流补充资料逐格抽取为带页码证据的事实；研报的正文、财务摘要表、预测表与首页行情逐条抽取为陈述。
        3. 
      
      3. 核查：法定科目直接比对披露值；多义指标（净利率、ROE、EPS、周转率等）登记候选定义逐一计算并注明命中的口径；预测与估值用研报自身表格和行情做内部勾稽；所有比较按披露精度做 Decimal 区间相容判断。
        4. 
      
      4. 归因与建议：不相容时依次检验单位(E4)、期间(E2)、口径(E3)、计算(E5)，给出应为值、计算式、证据页与可直接替换的文本。
        5. 
      
      5. 缺口：真正缺材料的陈述列出缺哪一期哪一项，补充对应报告后重跑即可。
        6. 
    
      
    
      模型（可选）只在宿主给定的枚举中做语义绑定，不提交数值、公式或判定。审慎模式下不做口径推定，与旧版内核策略一致。
      
    
      状态含义
      
    
      • 已核实与披露或登记公式在披露精度下相容
      • 有误所有登记口径均不相容，并给出归因
      • 未能核实缺材料或指标定义缺口（不等于有误）
      • 不判定观点、目标价、行情输入等不属于事实核查
      
    
      事实、推论与观点
      
    
      每条陈述标注性质：事实（历史财务与已发生的经营数据，对回原始披露核查）、推论（预测与基于预测的估值，检查与研报自身预测表和行情的勾稽）、观点（目标价、评级等，不作真伪判定）。内部勾稽要求独立操作数，自身与自身比较不能核实，历史事实仍需要外部披露依据。
      
    
      错误类型
      
    
      E1 数值错误 · E2 期间错误 · E3 口径错误 · E4 单位错误 · E5 计算错误 · E6 引用错误 · E7 逻辑比较错误 · E8 缺少核查前提（保留未能核实）· E9 披露版本错误。期间、口径和版本诊断需要来源证据，不能只凭相同金额反推。
      
    
      推定与假设
      
    
      标准模式按通行惯例推定并逐条披露：未写口径按合并报表、未写期间按上下文、多义指标按登记的候选定义逐一计算、负基数增速按 |基期|、报表“-”按零列报、单季由累计数推算、预测与估值改核研报内部勾稽。每条结果的“推定与假设”写明用到哪几项；审慎模式不做口径推定。
